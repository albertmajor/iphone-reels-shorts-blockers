## Réponses rapides

- **Peut-on désactiver les Reels d'Instagram ?** Non, Instagram n'a pas d'interrupteur.
- **Peut-on désactiver les Shorts de YouTube ?** En partie : la limite du fil Shorts peut être à zéro, mais les adultes peuvent l'ignorer.
- **Gratuit, rien à acheter, messages conservés :** StillTabs et FeedOff.
- **Traite le mieux ses utilisateurs :** StillTabs, la seule app qui passe les 14 contrôles.
- **Instagram uniquement pour les messages :** le mode Blackout de StillTabs (gratuit).
- **Besoin de TikTok aussi :** minulo (base gratuite, Pro payant).

## Réglages intégrés (sans app)

- **Instagram :** touchez le logo Instagram et choisissez **Abonnements** pour ne voir que les comptes suivis. Aucun interrupteur pour les Reels ou Explorer.
- **YouTube :** Vous → Paramètres → Gestion du temps → **Limite du fil Shorts**, jusqu'à zéro.
- **Temps d'écran :** limite des apps entières, donc les messages aussi.
