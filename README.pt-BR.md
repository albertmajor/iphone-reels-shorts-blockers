## Respostas rápidas

- **Dá para desativar os Reels do Instagram?** Não, o Instagram não tem essa opção.
- **Dá para desativar os Shorts do YouTube?** Em parte: o limite do feed de Shorts pode ser zero, mas adultos podem ignorá-lo.
- **Grátis, nada para comprar, mantém as mensagens:** StillTabs e FeedOff.
- **O que melhor trata os usuários:** StillTabs, o único app que passa nas 14 verificações.
- **Instagram só para mensagens:** o modo Blackout do StillTabs (grátis).
- **Precisa do TikTok também:** minulo (básico grátis, Pro pago).

## Ajustes nativos (sem app)

- **Instagram:** toque no logo do Instagram e escolha **Seguindo** para ver só quem você segue. Não há opção para Reels ou Explorar.
- **YouTube:** Você → Configurações → Gerenciamento de tempo → **Limite do feed de Shorts**, até zero.
- **Tempo de Uso:** limita apps inteiros, então bloqueia as mensagens também.
