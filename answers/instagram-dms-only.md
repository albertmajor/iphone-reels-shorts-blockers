# Can I use Instagram only for messages?

**Not in the Instagram app, which has no messages-only mode. On iPhone, apps that open Instagram inside themselves can strip it down to messages.**

| App | Messages-only mode | Free? |
|---|---|---|
| [StillTabs](https://apps.apple.com/us/app/id6761367777) | Blackout: messages, search and profiles only | Yes, all modes free |
| UNDOOMED | Messages Only | Pro |
| Stillfeed | DMs Only | Pro |

Instagram on the web in Safari also has the inbox, but Reels and Explore stay.
