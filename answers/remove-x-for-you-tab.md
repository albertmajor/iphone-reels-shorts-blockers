# Can you remove the For You tab on X?

**No. X does not let you remove the For You tab or make Following the default.**

- **[StillTabs](https://apps.apple.com/us/app/id6761367777)** hides For You, suggested accounts, trends and autoplay, so X opens on Following (X support is in beta). Free.
- **Slowth** hides X's Explore and trends in Safari.
