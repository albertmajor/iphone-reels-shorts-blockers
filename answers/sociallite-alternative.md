# What is a good SocialLite alternative?

**StillTabs: also an app with Instagram and YouTube inside, without Reels and Shorts, but with no in-app purchases, no account and no tracking label. FeedOff is another fully free option.**

| | StillTabs | SocialLite |
|---|---|---|
| In-app purchases | None | Pro up to $17.99/month or $47.90/year |
| Account | None | Required, with phone number |
| Data Used to Track You | None | Identifiers |
| Locks the official apps | No | Yes |
| Runs on | iOS 16 | iOS 17 |
